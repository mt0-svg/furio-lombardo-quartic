The plane quartic of Conjecture 1.6 of Furio and Lombardo has exactly four rational points, [0:0:1], [1:1:1], [2:0:1] and [-1:0:1].

This is AI-generated research: the results, proofs and code were found and written by AI. Credit goes to all the humans whose work it builds on.

**Proved in Lean 4:** `FurioLombardo.conjecture_1_6`, with Mathlib and only the standard axioms, checked against `FurioLombardo/Challenge.lean` by Comparator with the Lean kernel on GitHub's runners; the Lean kernel checks every finite computation of the proof. **By computation:** the certificates were written by the PARI/GP scripts and Lean programs of `code/`, and a second program in Sage recomputes the 2-adic logarithms, the lattice, the centres and the boxes of the covering from the exact data of the first programs (see the README).

Assets: the paper, `verification-v1.0.tar.gz` (the complete output of every check run for this release), and `furio-lombardo-quartic-x86_64-unknown-linux-gnu.tar.gz`, the Lake build of this tag that Comparator checked, which `lake build :release` and dependent packages download.
