The same proof and paper as v1.0 (Zenodo record [10.5281/zenodo.23049095](https://doi.org/10.5281/zenodo.23049095)); only the checks on GitHub change.

- `ci.yml` runs only on commits that touch the Lean build, cancels a superseded run, and restores the previous build (from the cache, else from the latest release) so that only what changed is compiled. Comparator compiles the challenge module again from its source.
- `release.yml` takes the green CI run of the tagged commit and compiles nothing again.
- The release no longer carries `.sha256` files: GitHub shows the sha256 of each asset.

Assets: the paper, `verification-v1.0.1.tar.gz` (the complete output of every check of the CI run), and `furio-lombardo-quartic-x86_64-unknown-linux-gnu.tar.gz`, the Lake build that Comparator checked, which `lake build :release` and dependent packages download.
