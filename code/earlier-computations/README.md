# Earlier computations

The PARI/GP computations made before the formal proof (section "Earlier computations" of the paper), and the exact data that the other programs start from. `data/` holds the lattice data, the centres, the Selmer images at v and the box lists of the recorded runs, and `export/` the text exports read by the second implementation of `code/second-implementations/local-group-covering`. Every script is run from this directory with `gp -q <script> < /dev/null`, as its header says.

## The cache directory

The scripts of the pipeline below keep their intermediate results under `/tmp/k21c/`:

- `nr/`: the field N of degree 84, its factorisations and its S-units;
- `sel/`: the 2-Selmer computation over K and the lattice at v;
- `sat/`: the square roots found by the saturation, so that a rerun of `sunits_n84_saturate.gp` resumes;
- `m9e/` and `m9export/`: the box lists and the text exports;
- `n84/`: the polynomial of N;
- `v2/`: the working files of `class_number_minkowski_run.sh`.

`sunits_n84_saturate.gp`, `prym_two_descent.gp`, `sigma_v_injective.gp`, `text_export.gp` and `boxes.gp` create the directories they write. `nr/` and `n84/` are not created by their writers: run `mkdir -p /tmp/k21c/nr /tmp/k21c/n84` first. Several scripts read a cache file instead of recomputing it when it is present (`sunits_n84.gp`, `sunits_n84_saturate.gp`, the functions of `prym_two_descent_lib.gp`); remove `/tmp/k21c` to run everything from the start.

Two remarks on these runs:

- `sunits_n84.gp` ends with a failed check: its S-units reach character rank 46, and the check asks for 53. It writes `nr/nsunits.bin` before that check, and `sunits_n84_saturate.gp` completes the basis to rank 53 and ends with RESULT PASS.
- `field_n84.gp` and `field_n84_galois.gp` produced the polynomials `field_n84_polynomial.gp` and `field_k13_polynomial.gp`, which the later steps read from this directory. `sunits_n84.gp` recomputes the three `nr/` files of step 8 when they are absent, so steps 6 to 8 are not needed to rerun steps 9 onwards.

`lattice_cert.gp` and `centres_cert.gp` read only files of this directory (`code/README.md`, "From the shipped files"). The scripts of other directories that read these caches are listed in `code/README.md`.

## Other files

`bitangents.gp` prints the bitangents of C; no later step reads it. `contact_conics.gp` writes `contact_conics_p0.ms`, a polynomial system for the contact conics through P0 in the input format of msolve, and `contact_conics_p0.rur` is the answer recorded for it; msolve is not part of this repository.
