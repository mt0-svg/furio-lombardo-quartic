# Code

The PARI/GP, Sage, GAP, Singular, Rust and Lean scripts of the paper, each next to its complete recorded output (`.out`, `.time`, and the data files it wrote). Paths are relative to the root of the repository.

- Each script says in its header where to run it and how. The scripts of a directory are run from that directory.
- In file names, `twist0` and `twist1` are the twists k = 0 and k = 1; `v`, `w12`, `w6` and `w7` are the places v, w_12, w_6 and w_7 of K; `prec<n>` is a p-adic working precision.
- The scripts that read or write Lean files find the Lean package at the root of the repository (`../../FurioLombardo/...` from a directory of `code/`). They were run with the package in a directory `lean/` of their working tree, so the recorded outputs that print these paths show `../../lean/FurioLombardo/...`.
- Some recorded outputs were written before the scripts and directories got their present names, and print the old names; `renames.tsv` maps each old path to the new one.
- `lib/` holds the shared code: `pball.gp` (ball arithmetic with proved error bounds over a totally ramified extension of Q_p), `richelot.gp` (descent by a Richelot isogeny), `td2loc.gp` (local images of the 2-descent map), and the Rust crate `rust-base` (finite fields, plane curves over finite fields, the Jacobian group law of the quartic).

## Rerunning

Tools: PARI/GP 2.17.4, Sage 10.9, GAP and Singular (in `jacobian-over-q` and `second-implementations/two-descent`), Rust, and Lean for the `.lean` scripts.

### From the shipped files

These read only files of this repository, in this order:

1. `earlier-computations/lattice_cert.gp` (writes `data/lattice_twist*.bin`), then `centres_cert.gp` (reads them, `data/boxes_twist*.txt` and `export/centres_pari_twist*.txt`; writes `data/centres_twist*.txt`).
2. `selmer-local-conditions/selmer_rows.gp`, once per twist and place as in the recorded outputs, then with `SB_PLACE=X`, with `SB_GENS` set to `FurioLombardo/Discharge/SelmerBasis/SUnitData.lean`.
3. `field/class_number_primes_rerun.sh`: reruns `class_number_primes.gp` (which reads `field_bnf.bin` of `class_group_search.gp`) and compares with `FurioLombardo/M2/Data`, with exit status 1 if they differ.
4. `earlier-computations/class_number_minkowski_run.sh`, the class number by explicit generators.
5. `second-implementations/local-group-covering`, from its directory: `logs.sage` at precisions 400 and 1000, `lattice.sage`, `centres.sage`, `box_bounds.sage`, then `compare_certs.sage`, `compare_lattice_basis.sage` and `precision_check.sage`. The known-answer tests `abel_prym_kat.sage` and `pullback_kat.sage` run at any point. The precisions of the recorded runs are in the output names and first lines.
6. `second-implementations/descent-set`, from its directory: `field_and_bruin_identity.sage`, `support_determinant.sage`, `sunits_basis.sage`, `good_prime_sieve.sage`, `local_conditions_2_3.sage`, `final_classes.sage`, `coverings_kat.sage`.
7. `second-implementations/selmer-space`: `selmer_space_check.sage` and `sigma_check.sage`, on the shipped exports.
8. `jacobian-over-q`: `two_descent_algebra.gp`, `two_descent_galois_module.g`, `good_reduction.sing`, `two_descent_local_images.gp`, `fake_selmer_group.gp`, `known_classes_images.gp`, `square_class_map_checks.gp`. `second-implementations/two-descent`: `geometry_check.gp`, `algebra_arithmetic_check.gp`, `local_image_2_check.gp`, `fake_selmer_group_check.gp`, then `known_classes_images_check.gp`, `local_image_2_divisors.gp`, `local_images_7_inf_check.gp`, `divisor_r_comparison.gp`, `local_image_2_elementary.gp`; `galois_group_check.sage`, `galois_module_check.g` and `good_reduction_check.sing` alone.
9. `lpoly` (writes `jacobian-over-q/lpoly/lpoly_C.txt` from `jacobian-over-q/lpoly/C.txt`), `jorder` (writes `jacobian-over-q/mw-sieve/jorder_C.txt`), `mwsieve`.

### Shipped data whose writer is not shipped

In `earlier-computations`: `local_images_twist*_e*.bin` (the local images of the Selmer computation at the places above 2), `export/centres_pari_twist*.txt` (the PARI/GP values at the centres, exported from the covering run), `logs_q23.sobj` (the logarithms over Q_23 of an earlier rank bound), `richelot_data.gp` (the Richelot data of the Prym curves), `phi_known_lifts.gp` (the values of phi_k at the known lifts), `pullback_known_lifts.gp` (the tiny integrals at the known lifts), `field_l42_polynomial.gp` (the polynomial of L), `prym_fields.gp` (the fields of definition of the Prym curves). In `second-implementations/local-group-covering`: `exact_global_data.sage` (the exact global data as Sage text).

### Shell drivers

The header of each shell driver says how its recorded run was made: most ran each command under a memory-capping wrapper, `cap`, that is not part of this repository, and the commands themselves run without it. `local-group/di_values_ball_run.sh`, `selmer-global-bound/sunit_data_install.sh`, `selmer-local-conditions/lean_build_w7.sh` and `final_check_w7.sh` take lock files under `/tmp` with `flock`, and `final_check_w7.sh` calls a tool that is not shipped, `sorry-leaves`, to list the sorry leaves of `coordCond_w7`. The `lean_build_*.sh` and `lean_check_*.sh` scripts of `selmer-global-bound` run Lean under `systemd-run` with a memory limit. `formal-proof/clean_build.sh` reads a command prefix and a lock file from the environment (`RUN_WRAP` and `LOCK`, empty by default).

### Rust

The two crates build on their own, with `lib/rust-base` as a path dependency and a `Cargo.lock` each:

```
cargo build --release --manifest-path code/jacobian-over-q/lpoly/Cargo.toml
cargo build --release --manifest-path code/jacobian-over-q/mw-sieve/Cargo.toml
```

`mwsieve` reads `code/jacobian-over-q/lpoly/lpoly_C.txt` and `code/jacobian-over-q/mw-sieve/jorder_C.txt` by default, relative to the root of the repository.

## Second implementations

- `second-implementations/local-group-covering` (Sage), written separately from the mathematics alone, reads the exact global data, the points D_i and the box lists from text exports. Its outputs show: the logarithms at precision 1000 (`logs_prec1000.out`) and the agreement of the precisions claimed at 400 with the values at 1000 (`precision_check.out`); the lattice and the class e1 at the known lifts (`lattice.out`); the 82 and 22 centres of the two twists, none in pr(W), at precisions 400 and 1000 (`centres_prec400.out`, `centres_prec1000.out`); the bounds v_M, the covering of each disc and the 11 and 12 exclusions (`box_bounds.out`, ALL CHECKS PASS); no disagreement with the first programs over the 82 and 22 centres and over the 84 and 24 constant and tail boxes (`compare_certs.out`), and the same class at every centre after matching the bases (`compare_lattice_basis.out`); known-answer tests of the Abel-Prym map and of the pullback identity (`abel_prym_kat.out`, `pullback_kat.out`). `exact_data_check.sage` has no recorded output.
- `second-implementations/descent-set` (Sage), written separately, redoes the descent set: a basis of K(S,2), 18 generators of F_2-rank 18 (`sunits_basis.out`); the sieve, 8 survivors up to 199 (`good_prime_sieve.out`); the local conditions at 2 and 3 by its own coverings, 40 and 20 leaves, which keep 2 classes (`local_conditions_2_3.out`); their identification with delta_0 and delta_1 (`final_classes.out`); 1120 local square decisions against `nfislocalpower` with no mismatch (`coverings_kat.out`).
- `second-implementations/selmer-space` (Sage, its own parser and linear algebra) takes as given the generator coordinates and local images that `selmer_space_export.gp` and `sigma_export.gp` export from the runs of `earlier-computations/prym_two_descent.gp` and `sigma_v_injective.gp`, and redoes the linear algebra over F_2: dim X = 19 and an image of dimension 4 at v for each twist, the same subspace at v as `sigma_check.sage` (`selmer_space_check.out`); sigma_v injective on the 2-Selmer group, and the relation phi_a + phi_b as the only one among T, phi_a, phi_b (`sigma_check.out`). Both end with RESULT PASS.
